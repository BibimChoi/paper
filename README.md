## 보는 법

| 키 | 동작 |
|---|---|
| `→` `Space` | 다음 슬라이드 |
| `←` | 이전 슬라이드 |
| `O` | 목차 (클릭해서 점프) |
| `F` | 전체화면 |

`Ctrl+P` 로 인쇄하면 **슬라이드 한 장이 한 페이지**로 나옵니다.

외부 의존성이 없습니다. 스타일·스크립트·차트가 전부 파일 안에 들어 있습니다. 인터넷이 없으면 본문 글꼴만 시스템 기본으로 바뀌고 레이아웃은 그대로입니다.

## 구성

두 덱 모두 같은 흐름입니다 — **목적 → 전제 → 무엇을 물었나 → 실험 설계 → 결과 → 결론과 한계**.

대본(`-script.txt`)에는 슬라이드마다 화면에 없는 말할 내용이 들어 있습니다.

## 차트에 대해

- **실측값** — 원문에 숫자가 명시된 것 (Expert-MAS 57→96.5%, HarnessFix +6.3~18.4% 등)
- **형태 재구성** — 곡선의 모양만 옮긴 개념도. 해당 그림 안에 그렇게 표기해두었습니다

정확한 좌표가 필요하면 원 논문을 보셔야 합니다.
